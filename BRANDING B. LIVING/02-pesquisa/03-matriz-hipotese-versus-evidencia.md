# Template 03: Matriz Hipotese versus Evidencia

Modulo relacionado: 2. Pesquisa

Objetivo: transformar hipoteses da Imersao em evidencias organizadas para sustentar o Diagnostico.

## Matriz

| Hipotese | Pergunta de pesquisa | Fonte | Evidencia encontrada | Recorrencia | Impacto | Consistencia | Nivel de confianca | Implicacao estrategica |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  | Baixa / Media / Alta | Baixo / Medio / Alto | Baixa / Media / Alta | Baixo / Medio / Alto |  |

## Tipos de fonte

- Entrevista interna
- Escuta qualitativa com cliente
- Desk research
- Concorrencia
- Avaliacoes publicas
- Dados comerciais
- Analytics
- Redes sociais
- Atendimento
- Observacao de jornada
- Material institucional

## Criterios de confianca

Baixa confianca:

- fonte unica;
- evidencia fraca;
- baixa recorrencia;
- pouca consistencia;
- impacto incerto.

Media confianca:

- mais de uma fonte;
- padrao parcialmente recorrente;
- impacto plausivel;
- ainda exige cuidado.

Alta confianca:

- fontes consistentes;
- recorrencia clara;
- impacto relevante;
- boa relacao com outros achados.

## Saida esperada

- Achados organizados.
- Hipoteses confirmadas, enfraquecidas ou abertas.
- Evidencias para Diagnostico.
- Nivel de confianca registrado.
