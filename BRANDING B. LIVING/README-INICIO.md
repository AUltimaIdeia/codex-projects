# B. Living Floripa - Projeto de Branding

Status: projeto de cliente iniciado

Biblioteca original preservada em: C:\Users\BRANDING

## Como usar este projeto

Este projeto deve ser usado para executar o branding real da B. Living Floripa usando o Sistema Aplicado de Branding.

A pasta C:\Users\BRANDING deve permanecer original, sem edicoes. Aqui, nesta pasta do cliente, os templates podem ser preenchidos, duplicados, adaptados e transformados em entregas.

## Primeira etapa

Comecar pelo Modulo 1: Imersao.

Arquivos iniciais:

- 01-imersao/01-briefing-imersao.md
- 01-imersao/02-matriz-pedido-versus-problema.md
- 02-pesquisa/03-matriz-hipotese-versus-evidencia.md

## Primeira entrega interna

Criar a Leitura Inicial do Desafio da B. Living, separando:

- pedido declarado;
- contexto do negocio;
- hipoteses;
- possivel problema real;
- materiais existentes;
- lacunas de pesquisa;
- proximos passos.

## Regra principal

Nao comecar por identidade visual. Comecar entendendo valor, negocio, percepcao e experiencia.
