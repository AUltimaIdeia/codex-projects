# Teste Visual - Landing Preview

Este teste existe para validar consistencia visual antes de produzir a landing page completa.

Use `index.html` como prancha renderizavel. Ele usa tokens do brandbook e aponta para o logo SVG real do acervo pesado.

Obrigatorio: logo oficial em SVG e texto serifado/display em caixa alta.

Nao trate esta pagina como layout final. Ela e uma prova de controle visual.
