# Teste 02 - Landing Home Real

Este teste valida se a identidade visual da B. Living se sustenta em uma aplicacao concreta de landing page.

Ele deve ser mais confiavel do que uma imagem gerada por prompt, porque usa:

- logo SVG real;
- obrigatoriedade de logo oficial, nao assinatura simulada;
- tokens oficiais;
- tipografia oficial, com serifada/display em caixa alta;
- estrutura de landing;
- copy alinhada ao brandbook;
- checklist de rejeicao do protocolo de consistencia.

Nao e a landing final. E uma prova de direcao.
