# Prompt Seguro - Teste De Consistencia Visual

Use este prompt no novo workspace da B. Living quando quiser testar consistencia visual sem cair em imagem generica.

```text
Leia primeiro:

- ABRIR_AQUI.md
- 05-fonte-oficial/FONTE_OFICIAL_PRODUCAO_B_LIVING.md
- 05-fonte-oficial/DIRETRIZES_PARA_NOVOS_MATERIAIS.md
- 05-fonte-oficial/PROTOCOLO_DE_CONSISTENCIA_VISUAL.md
- 05-fonte-oficial/BRIEF_BASE_LANDING_PAGE.md
- 05-fonte-oficial/EXEMPLO_REJEITADO_IMAGEM_1_GERADA.md

Nao gere uma imagem livre por prompt.

Quero um teste visual seguro da identidade B. Living.

Crie ou revise um layout renderizavel em HTML/CSS para uma prancha horizontal 16:9 de validacao da landing page, usando obrigatoriamente:

- logo real em SVG apontado pelo README-LOGOS;
- usar obrigatoriamente a logo oficial em SVG, nunca texto simulando logo;
- tokens reais do DESIGN.md e DESIGN.json;
- fonte display oficial: Bodoni Moda, Bodoni 72, Didot, Bodoni MT, Georgia, Times New Roman, serif;
- toda chamada em fonte display/serifada deve estar em CAIXA ALTA;
- fonte de apoio oficial: Montserrat, Avenir Next, Helvetica Neue, Segoe UI, Arial, sans-serif;
- azul profundo como campo dominante;
- warm paper/off-white para texto;
- brass apenas como linha fina, ponto ou detalhe;
- composicao editorial, silenciosa e precisa;
- tese "Antes do imovel, vem a decisao.";
- frase guia "Curadoria para decisoes imobiliarias de alto padrao.";
- Rafael, equipe, metodo, criterio, leitura e confianca como provas.

Apos criar o HTML/CSS, renderize uma imagem PNG ou screenshot do layout.

Antes de entregar, compare contra o EXEMPLO_REJEITADO_IMAGEM_1_GERADA.md e explique em poucas linhas por que o novo resultado nao repete aqueles erros.

Rejeite automaticamente qualquer resultado que:

- use Playfair Display, Suisse Intl ou fonte inventada;
- use chamada serifada/display em caixa baixa ou caixa mista;
- recrie o logo em texto;
- omita a logo oficial;
- invente paleta em hex como se fosse oficial;
- pareca brandbook extension generico;
- use mapa turistico como estetica principal;
- pareca imobiliaria premium comum;
- use dourado/brass como luxo obvio;
- adicione versao, data ou assinatura que nao existe.

O objetivo e me tranquilizar de que a identidade do brandbook pode ser aplicada com consistencia real antes de criar a landing page completa.
```
