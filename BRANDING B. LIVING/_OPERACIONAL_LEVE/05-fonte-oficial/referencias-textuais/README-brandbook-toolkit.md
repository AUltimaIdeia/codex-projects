# Brandbook Toolkit - B. Living Floripa

Este toolkit organiza os arquivos e diretrizes da marca B. Living Floripa para aplicacao, aprovacao e evolucao.

## Como usar

1. Comece pelo brandbook master em `01-Brandbook/brandbook-b-living-master.md`.
2. Use as pastas de assets para armazenar arquivos finais e editaveis.
3. Use os criterios do brandbook para aprovar pecas antes de publicar.
4. Mantenha arquivos antigos ou experimentais fora das pastas finais.

## Estrutura

- `01-Brandbook`: documento central da marca.
- `02-Logos`: logo atual, versoes de uso e assinaturas.
- `03-Cores`: paleta, codigos e exemplos.
- `04-Tipografia`: fontes, hierarquia e orientacoes.
- `05-Grafismos`: elementos graficos permitidos.
- `06-Imagens`: direcao fotografica, imagens aprovadas e referencias.
- `07-Templates`: modelos editaveis gerais.
- `08-Redes-sociais`: posts, stories, destaques e capas.
- `09-Apresentacoes`: apresentacoes institucionais e comerciais.
- `10-Propostas`: modelos de proposta e materiais comerciais.
- `11-Materiais-impressos`: convites, materiais fisicos e sinalizacao.
- `12-Fornecedores`: guias rapidos para parceiros externos.

## Regra principal

A B. Living deve ser aplicada como uma marca de curadoria imobiliaria de alto padrao, nao como uma imobiliaria-vitrine.
