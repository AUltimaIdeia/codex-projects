# Ativos Oficiais B. Living

Esta pasta guarda copias de trabalho dos ativos enviados pelo cliente para producao de novos materiais da B. Living.

Os arquivos originais permanecem preservados nos locais de origem. Para novas pecas dentro deste projeto, usar os arquivos desta pasta como referencia operacional.

## Estrutura

- `icone-b/`
  - Icones PNG do monograma B.
  - Uso recomendado: favicon, avatar, marca d'agua discreta, selo visual, detalhe institucional ou aplicacao compacta quando o SVG nao for necessario.

- `logo-fachada-svg/`
  - Logos SVG da versao fachada B. Living Imoveis.
  - Inclui versoes principais e compactas em variacoes de cor.

## Regras De Uso

- Nunca recriar a logo digitando o nome da marca.
- Sempre aplicar logo a partir de arquivo oficial SVG ou PNG enviado.
- Para fundo azul profundo ou imagem escura, priorizar versoes `BRANCA`, `BEGE CLARO` ou `BEGE`.
- Para fundo warm paper/off-white, priorizar versoes `AZUL ESCURO` ou `AZUL PRINCIPAL`.
- Usar `PRATA` ou metalizado apenas como detalhe discreto, quando a peca pedir acabamento institucional ou aplicado.
- Usar a versao compacta em posts, stories, capas, selos, marcadores e composicoes com pouco espaco.
- Usar a versao fachada completa quando a presenca institucional com "Imoveis" for importante.

## Observacao Sobre Fontes

Estes arquivos organizam logos e icones. As fontes oficiais ainda devem ser adicionadas em uma pasta separada, preferencialmente:

`05-fonte-oficial/ativos-oficiais/fontes/`

Quando os arquivos `.otf`, `.ttf`, `.woff` ou `.woff2` forem enviados, registrar aqui:

- fonte serifada principal para titulos;
- fonte sans de apoio;
- regras de caixa alta, pesos e usos.
