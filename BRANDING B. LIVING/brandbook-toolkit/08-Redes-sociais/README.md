# Redes Sociais - B. Living

Esta pasta mantem apenas a prancha visual final aprovada como referencia para reproducao da identidade da B. Living nas redes sociais.

Arquivo principal:
- `kit-visual-b-living-prancha-referencia-final.png`

Use esta prancha como base de direcao para novas pecas: logo, paleta, tipografia, textura, tratamentos, elementos graficos, aplicacoes, icone/assinatura e linguagem visual.

Evitar nas novas criacoes:
- ondas/patterns rejeitados;
- excesso de dourado;
- estetica de resort, clube nautico, construtora ou imobiliaria generica;
- colagem desconexa de referencias;
- luxo obvio ou ostentativo.
