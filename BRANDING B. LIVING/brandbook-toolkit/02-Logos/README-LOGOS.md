# Indice de Logos - B. Living Floripa

Status: fonte de contexto visual do projeto

## Estrutura recebida

As variacoes de logo estao organizadas em tres familias:

- `LOGO PRINCIPAL`: assinatura principal B. Living.
- `LOGO COMPACTA`: versao compacta para icone, assinatura reduzida e composicoes de apoio.
- `LOGO FACHADA`: versoes com "Imoveis", indicadas para contexto fisico, fachada e aplicacoes institucionais especificas.

Cada familia possui arquivos em:

- `SVG`: preferencial para layouts editaveis e renderizacao limpa.
- `PNG`: preferencial para mockups rapidos e aplicacoes raster.
- `PDF`: uso grafico/fornecedores.

## Versoes recomendadas

### Uso principal

- Fundo escuro / azul profundo: usar `BEGE CLARO`, `BEGE` ou `BRANCA`.
- Fundo claro / off-white: usar `AZUL ESCURO`, `AZUL PRINCIPAL` ou `PRETA`.
- Uso premium discreto: priorizar `BEGE CLARO` sobre azul profundo.

### Uso de icone

Usar `LOGO COMPACTA`, preferencialmente em:

- capas de destaque;
- avatar/assinatura reduzida;
- posts com pouco espaco;
- marcadores de sistema visual;
- canto de templates.

### Uso de fachada

Usar `LOGO FACHADA` quando a aplicacao exigir leitura fisica ou institucional com "Imoveis".

## Decisoes de aplicacao

- A logo principal esta preservada.
- A prancha visual e os proximos materiais devem usar logo real, nao assinatura textual provisoria.
- A versao compacta passa a funcionar como icone/assinatura do sistema.
- Evitar usar prata como padrao digital por peso de arquivo e risco de parecer luxo obvio.
- Evitar excesso de dourado ou metalizado como protagonista.

## Arquivos de referencia para a prancha

- Principal em fundo escuro: `LOGO PRINCIPAL/SVG/B. LIVING LOGO - BEGE CLARO.svg`
- Principal em fundo claro: `LOGO PRINCIPAL/SVG/B. LIVING LOGO - AZUL ESCURO.svg`
- Compacta em fundo escuro: `LOGO COMPACTA/SVG/Logo B. LIVING COMPACTA - BEGE CLARO.svg`
- Compacta em fundo claro: `LOGO COMPACTA/SVG/Logo B. LIVING COMPACTA - AZUL ESCURO.svg`
- Fachada em fundo escuro: `LOGO FACHADA/SVG/B. LIVING IMOVEIS LOGO - BEGE CLARO.svg` se houver versao sem acento no nome; caso contrario, usar o arquivo equivalente com acento em `IMOVEIS`.
