# Brandbook Editorial HTML

Pasta reservada para a montagem visual do brandbook completo da B. Living.

Fluxo aprovado:

1. Arquitetura editorial.
2. Copy por capitulo.
3. Aprovacao da copy e funcao visual.
4. Montagem HTML/CSS 16:9.
5. Previews PNG por pagina/capitulo.
6. Exportacao PDF.

Nao iniciar layout final de um capitulo antes da aprovacao da respectiva copy.
