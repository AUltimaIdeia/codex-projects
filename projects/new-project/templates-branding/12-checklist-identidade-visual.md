# Template 12: Checklist de Identidade Visual

Modulo relacionado: 8. Identidade Visual

Objetivo: avaliar se o sistema visual traduz a estrategia, gera reconhecimento e funciona em aplicacoes reais.

## 1. Criterios estrategicos

- [ ] O visual nasce da Plataforma.
- [ ] Expressa personalidade.
- [ ] Sustenta a promessa.
- [ ] Dialoga com a Identidade Verbal.
- [ ] Diferencia a marca da categoria.
- [ ] Preserva ou evolui equities com criterio.

## 2. Criterios de reconhecimento

- [ ] A marca e reconhecivel sem depender apenas do logo.
- [ ] Paleta tem papel claro.
- [ ] Tipografia tem criterio.
- [ ] Grafismos ou elementos visuais sao proprietarios.
- [ ] Estilo de imagem e consistente.
- [ ] Composicao tem padrao reconhecivel.

## 3. Criterios tecnicos

- [ ] Logo funciona em reducao.
- [ ] Contraste adequado.
- [ ] Legibilidade adequada.
- [ ] Versoes em fundo claro e escuro.
- [ ] Versao monocromatica.
- [ ] Sistema aplicavel em digital e impresso.
- [ ] Custo de producao viavel.

## 4. Criterios de aplicacao

- [ ] Funciona no site.
- [ ] Funciona em redes sociais.
- [ ] Funciona em proposta/apresentacao.
- [ ] Funciona em materiais comerciais.
- [ ] Funciona em ponto fisico, embalagem ou uniforme, quando aplicavel.
- [ ] Tem exemplos corretos e incorretos.
