# Template 18: Checklist de Lancamento

Modulo relacionado: 9. Comunicacao e 10. Implementacao, Gestao e Mensuracao

Objetivo: verificar se a marca, campanha, identidade ou comunicacao esta pronta para ir a publico com consistencia.

## 1. Estrategia

- [ ] Posicionamento aprovado.
- [ ] Proposta de valor aprovada.
- [ ] Promessa validada.
- [ ] Mensagens prioritarias definidas.
- [ ] Publicos claros.
- [ ] Objetivo do lancamento definido.

## 2. Experiencia

- [ ] Pontos de contato criticos revisados.
- [ ] Gaps relevantes tratados ou assumidos.
- [ ] Atendimento preparado.
- [ ] WhatsApp ou canal de contato preparado, quando aplicavel.
- [ ] Equipe alinhada sobre promessa e comportamento esperado.

## 3. Identidade verbal

- [ ] Tom de voz definido.
- [ ] Mensagens-chave aprovadas.
- [ ] Textos principais revisados.
- [ ] Respostas para duvidas previsiveis preparadas.
- [ ] Linguagem de momentos sensiveis definida.

## 4. Identidade visual

- [ ] Logo e assinaturas finais.
- [ ] Paleta e tipografia aplicadas corretamente.
- [ ] Pecas principais revisadas.
- [ ] Legibilidade e contraste verificados.
- [ ] Aplicacoes prioritarias prontas.

## 5. Comunicacao

- [ ] Plano de canais definido.
- [ ] Campanha ou ideia orientadora aprovada, quando aplicavel.
- [ ] Conteudos principais aprovados.
- [ ] CTAs definidos.
- [ ] Responsaveis por publicacao definidos.

## 6. Implementacao

- [ ] Arquivos finais organizados.
- [ ] Toolkit entregue.
- [ ] Brandbook ou guia rapido disponivel.
- [ ] Checklist de aprovacao compartilhado.
- [ ] Fornecedores orientados.

## 7. Mensuracao

- [ ] Indicadores definidos.
- [ ] Fonte dos indicadores definida.
- [ ] Responsavel por leitura definido.
- [ ] Primeira revisao planejada.

## Saida esperada

- Lancamento com riscos mapeados.
- Pendencias claras.
- Responsaveis definidos.
