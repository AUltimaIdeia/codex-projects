# Comercial Branding

Camada comercial do Sistema Aplicado de Branding.

Status: primeira versao operacional

## Arquivos

0. `00-direcao-visual-a-ultima-ideia.md`
   Guia para aplicar a identidade visual e verbal da A Ultima Ideia nos materiais comerciais.

1. `01-proposta-comercial-branding.md`
   Modelo de proposta para apresentar escopo, metodo, entregaveis, validacoes e investimento.

2. `02-apresentacao-base-branding.md`
   Estrutura slide a slide para apresentar o metodo, conduzir diagnostico, vender a proposta ou apresentar a entrega estrategica.

3. `03-roteiro-reuniao-venda-branding.md`
   Roteiro de conversa para entender o cliente, qualificar o projeto e preparar proposta.

## Regra de uso

Nao vender apenas identidade visual, logo ou campanha. Vender um processo de construcao de valor, coerencia e aplicacao de marca.

Frase guia:

> O projeto organiza a marca como sistema: entende o negocio, interpreta valor, define estrategia, prova na experiencia, expressa em linguagem e visual, comunica com consistencia e entrega ferramentas para gestao.

## Direcao visual

Usar a identidade da A Ultima Ideia como camada de apresentacao:

- fundo Obsidian;
- texto Ritual White;
- Graphite para superficies secundarias;
- Concrete para metadados;
- Idea Red como interrupcao, ponto e decisao;
- composicao editorial, cinematografica e precisa;
- linguagem direta, densa e seletiva.
