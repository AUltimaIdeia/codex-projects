# Landing Page A Ultima Ideia - Organizacao

Esta pasta organiza tudo que ja foi produzido para evitar mistura entre versoes.

## Regra principal

Nao edite diretamente a pasta `01_final-publicavel`.

A versao publicavel deve ficar preservada. Novas ideias, ajustes, testes ou versoes alternativas devem ser criados dentro de `05_area-de-trabalho-novas-versoes`.

## Estrutura

- `01_final-publicavel`: copia preservada da landing atual, pronta para consulta/publicacao.
- `02_versoes-anteriores`: screenshots e evidencias das tentativas anteriores.
- `03_referencias-visuais`: referencias visuais usadas no processo.
- `04_qa-screenshots`: capturas de validacao da landing atual.
- `05_area-de-trabalho-novas-versoes`: unica area editavel para novas tentativas.

## Como trabalhar daqui pra frente

1. Cada novo chat deve usar uma subpasta propria dentro de `05_area-de-trabalho-novas-versoes`.
2. Nao misture arquivos entre `v1-experimental`, `v2-experimental` e outras novas versoes.
3. Quando uma versao for aprovada, coloque uma copia em `aprovada-para-substituir-final`.
4. Substitua `01_final-publicavel` somente depois de aprovacao explicita.
5. Nao apague arquivos antigos sem aprovacao explicita.
