# Projeto Piloto Branding

Status: piloto ficticio preenchido

Marca ficticia: Casa Aurora

Categoria: cafeteria, brunch e mercearia afetiva de bairro

Objetivo do piloto: testar o Sistema Aplicado de Branding em um caso pequeno/local/de varejo, preenchendo os principais raciocinios do metodo sem depender de cliente real.
