# Prompt request correction

User correction: use "pedido de prompt" or "solicitacao de acao", not "pedido de compra".

Working rule for this project and ongoing conversation:

- When improving the user's request, treat it as prompt/action design.
- At the end of relevant work, provide one improved prompt sentence and one example sentence.
- Do not frame it as a purchase request unless the user explicitly asks for buying, checkout or acquisition.

Improved prompt sentence:

Mapeie fontes oficiais, extraia referencias visuais e estrategicas, organize os achados em uma biblioteca reutilizavel e entregue uma sintese objetiva com links, evidencias e aplicacoes praticas.

Example sentence:

Analise o ecossistema digital da Ana Couto, salve capturas e assets relevantes, gere um design.md aplicavel e liste links oficiais ou relacionados com uma opiniao curta sobre cada um.
