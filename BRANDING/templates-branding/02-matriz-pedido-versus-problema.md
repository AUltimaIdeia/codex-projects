# Template 02: Matriz Pedido versus Problema

Modulo relacionado: 1. Imersao

Objetivo: separar o que o cliente pediu do problema real que precisa ser investigado.

## Matriz

| Campo | Preenchimento |
|---|---|
| Pedido literal do cliente |  |
| Motivo declarado |  |
| Urgencia percebida |  |
| Sintomas citados |  |
| Evidencias disponiveis |  |
| Possivel problema por tras do pedido |  |
| Hipoteses alternativas |  |
| O que ainda precisa ser investigado |  |
| Risco de aceitar o pedido como diagnostico |  |
| Decisao de pesquisa recomendada |  |

## Perguntas de apoio

- O pedido e uma solucao antecipada?
- O cliente esta descrevendo causa ou sintoma?
- O problema e de marca, negocio, experiencia, comunicacao, venda ou operacao?
- O pedido pode estar escondendo perda de valor percebido?
- Que evidencia falta para diagnosticar?

## Classificacao inicial

Marque uma opcao:

- [ ] Pedido provavelmente correto.
- [ ] Pedido parcialmente correto, mas precisa investigar causa.
- [ ] Pedido parece sintoma de outro problema.
- [ ] Pedido ainda nao pode ser avaliado.

## Saida esperada

- Problema a investigar.
- Hipoteses para Pesquisa.
- Alinhamento com cliente sobre nao pular direto para solucao.
