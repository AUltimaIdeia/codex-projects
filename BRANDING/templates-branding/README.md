Status: primeira versao operacional

## Como usar

Use estes templates como ferramentas de conducao, analise, decisao e apresentacao. Eles nao substituem julgamento estrategico; eles organizam o raciocinio para reduzir achismo, acelerar alinhamento e tornar as decisoes validaveis.

## Regra de uso

Antes de transformar qualquer conclusao em decisao, verifique:

- Qual evidencia sustenta?
- Qual nivel de confianca?
- Qual implicacao estrategica?
- O cliente precisa validar?
- Isso altera direcao, criterio, promessa, posicionamento, identidade, comunicacao ou gestao?

Se alterar direcao, precisa de validacao.
