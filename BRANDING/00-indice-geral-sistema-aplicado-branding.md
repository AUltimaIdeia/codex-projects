# Indice Geral: Sistema Aplicado de Branding

Status: indice operacional v1

Data: 2026-05-04

## 1. Para que este indice existe

Este arquivo organiza todos os documentos oficiais criados para o Sistema Aplicado de Branding. Use como ponto de partida para navegar entre manual, modulos, templates e materiais comerciais.

O sistema esta estruturado para uso em quatro situacoes:

- conduzir projetos reais de branding;
- montar proposta comercial;
- apresentar estrategia ao cliente;
- entregar brandbook, toolkit e governanca.

## 6. Fluxo recomendado para usar em um projeto real

### Antes da proposta

1. Usar `comercial-branding/03-roteiro-reuniao-venda-branding.md`.
2. Preencher sinais iniciais do desafio.
3. Definir porte do projeto: pequeno, medio ou robusto.
4. Montar proposta com `comercial-branding/01-proposta-comercial-branding.md`.

### Ao iniciar o projeto

1. Abrir `manual-oficial-sistema-aplicado-branding-v1.md`.
2. Conduzir Modulo 1 com `templates-branding/01-briefing-imersao.md`.
3. Separar pedido e problema com `templates-branding/02-matriz-pedido-versus-problema.md`.

### Durante estrategia

1. Levantar evidencias com `03-matriz-hipotese-versus-evidencia.md`.
2. Diagnosticar com `04-matriz-diagnostico.md`.
3. Organizar coerencia com `05-mapa-e-faz-fala.md`.
4. Decodificar valor com `06-matriz-preservar-fortalecer-ressignificar-abandonar.md`.
5. Consolidar Plataforma com `07-canvas-plataforma-branding.md`.

### Durante experiencia e identidade

1. Mapear jornada com `08-jornada-do-cliente.md`.
2. Cruzar promessa e entrega com `09-matriz-promessa-versus-entrega.md`.
3. Definir verbal com `10-guia-tom-de-voz.md` e `11-matriz-mensagens-chave.md`.
4. Avaliar visual com `12-checklist-identidade-visual.md`.
5. Priorizar aplicacoes com `13-mapa-aplicacoes.md`.

### Durante comunicacao e implementacao

1. Planejar canais com `14-plano-de-canais.md`.
2. Estruturar campanha, se houver, com `15-estrutura-de-campanha.md`.
3. Criar big idea, se aplicavel, com `16-big-idea-canvas.md`.
4. Criar calendario, se aplicavel, com `17-calendario-de-conteudo.md`.
5. Checar lancamento com `18-checklist-de-lancamento.md`.
6. Consolidar entrega com `19-brandbook.md`, `20-toolkit.md`, `21-painel-de-metricas.md` e `22-rotina-de-governanca.md`.

## 7. Regras operacionais

- Nao pular Diagnostico para ir direto para identidade.
- Nao transformar pedido inicial em conclusao.
- Nao vender logo como substituto de branding.
- Nao prometer o que a experiencia nao consegue provar.
- Nao criar comunicacao sem papel de canal e mensagem.
- Nao entregar brandbook apenas como manual de logo.
- Nao medir apenas performance; considerar marca, experiencia, comunicacao e negocio.

## 8. Proximo passo recomendado

Com o sistema, templates e camada comercial organizados, o proximo passo recomendado e criar um **projeto piloto preenchido**.

Objetivo do piloto:

- testar os templates;
- ver se as perguntas estao suficientes;
- identificar lacunas;
- transformar o sistema em material de venda e entrega ainda mais concreto.

Formato sugerido:

1. Escolher uma marca real ou ficticia.
2. Preencher os templates essenciais.
3. Gerar uma apresentacao de exemplo.
4. Gerar um brandbook exemplo.
5. Ajustar o metodo com base no uso.
